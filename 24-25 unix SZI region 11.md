У нас есть 3 файла:
- контейнер с приватным ключом
- пароль
- зашифрованное сообщение
И нам неизвестен пароль, важно понимать, что пароль это в любом случае, какое то известное слово или пароль, который входит в словарь для перебора паролей. Иначе если это реально случайный пароль, то перебрать его будет просто невозможно. К счастью у нас есть файлик `rockyou.txt`, который содержит в себе `133мб` текста, который используется при `брутфорсе`.
![[Pasted image 20260511140855.png]]
То есть будем из `rockyou.txt` подставлять пароли в `final.p12` и извлечём приватный ключ.
Есть 2 варианта решить эту задачу, первый способ это прописать скрипт на питоне, давайте его напишем, назовём brute.py.
```python
import subprocess
f = open('/usr/share/wordlists/rockyou.txt', encoding='latin-1').readlines()
for x in f:
	x = x.strip()
	result = subprocess.run(
	f"openssl pkcs12 -in final.p12 -out decrypted_key.pem -nodes -passin:pass{x}",
	 shell=True,
	 capture_output=True
	 )
	if result.returncode == 0:
		print(x)
```
