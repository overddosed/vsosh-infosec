Используя команду:
```bash
openssl enc -d -aes-256-cbc -salt -in flag.txt.enc -out flag.txt -k JXrTLzijLbKI6VWx09JJnBNfDKbP5n

# openssl enc - Вызов модуля openssl для работы с симметричным шифрованием (encryption)

# -d (decrypt) - Флаг, который переключает утилиту в режим расшифровки

# -aes-256-cbc - Выбор алгоритма. AES-256: Один из самых надёжных стандартов шифрования в мире (длина ключа 256 бит). CBC (Cipher Block Chaining): Режим сцепления блоков, где каждый блок данных зависит от предыдущего.

# -salt - Указывает, что при шифровании использовалась "соль" (случайные данные, добавленные к паролю). Это стандарт для OpenSSL, которые защищает от атак по словарям.

# -in flag.txt.enc - Входной файл (зашифрованный флаг)

# -out flag.txt - Имя файла, в который будет записан результат (уже расшифрованный текст).

# -k ... - Ключ (пароль), который мы нашли ранее.
```
